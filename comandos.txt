****COMANDOS GIT****

VER CONFIGURACION: git config --global --list
git config --list

BORRAR CONFIGURACIONES: git config --global --unset user.name
git config --global --unset user.email
git config --global --list

CONSULTAR NOMBRE DE RAMA: git branch

CAMBIAR NOMBRE RAMA: git branch -M main


GUARDAR CMABIOS Y SUBIR: git push -u origin main
